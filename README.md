End-to-end machine learning project to predict UK police stop-and-search outcomes from monthly public records (February 2023 to January 2026). The workflow covers data ingestion, cleaning, feature engineering, cloud model training, artifact retrieval, and local model evaluation.

## Project Summary

- Problem: Binary classification of stop-and-search outcome ("A no further action disposal" vs other outcomes).
- Data scope: 1,459 monthly CSV files merged from UK police stop-and-search datasets.
- Core stack: Python, pandas, scikit-learn, XGBoost, AWS SageMaker, S3, boto3.
- Deployment note: No hosted endpoint is deployed in this workflow (no ongoing hosting cost from endpoint runtime).

## Measured Project Metrics

- Ingested monthly CSV files: 1,459
- Final training feature count: 55 features (56 total columns including label)
- Latest SageMaker training duration: 842 seconds (~14m 02s)
- Local experiment performance (sampled advanced pipeline):
  - Tuned XGBoost: ROC-AUC 0.8801, Accuracy 0.8236, F1 0.7008
  - XGBoost + Logistic ensemble: ROC-AUC 0.8781, Accuracy 0.8253, F1 0.7049

## Pipeline Overview

1. Ingest and merge monthly CSV files using recursive glob + pandas concat.
2. Clean data by dropping low-value/high-missing columns and handling nulls.
3. Build target label (Outcome_Binary) and time-derived features.
4. Encode categorical features and build final numeric training matrix.
5. Split into train/validation/test and export SageMaker-compatible CSV files.
6. Upload data to S3 and train XGBoost on SageMaker.
7. Retrieve model artifact from S3 and run local offline evaluation.
8. Tune classification threshold on validation for best test-time decisioning.
9. Run local improvement experiments (advanced features, tuning, ensemble).

## How to Run

### 1) Environment

- Python virtual environment is recommended.
- Install core packages:

```bash
pip install pandas numpy scikit-learn xgboost sagemaker boto3
```

### 2) Notebook workflow

Open and run:

- UK Stop and Search Data, 2023-02 -2026-01.ipynb

Execute cells in order to:

- Ingest and preprocess data
- Generate train/validation/test files
- Upload to S3 and train SageMaker model
- Download artifact and evaluate locally

### 3) Local improvement experiments

```bash
python uk_stop_search_accuracy_improvements.py
```

This script runs additional local optimization experiments and prints model comparison metrics.
